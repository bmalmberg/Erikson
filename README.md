# Erikson
War maps

**From Kursk to the Dnieper, 1943** (`index.html`): an interactive map of the Soviet offensives after Kursk, from the Orel and Kharkov operations to the Dnieper, Kiev and the end of 1943, based on John Erickson, *The Road to Berlin*, chapters 3–4. It covers 26 events in five series, with arrows, front lines, unit symbols and about 110 places. Base map: Natural Earth.
